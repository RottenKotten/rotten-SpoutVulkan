# SpoutVulkan

This repository is a fork of [leadedge/SpoutVulkan](https://github.com/leadedge/SpoutVulkan), adapted for further development and use as a reusable library rather than a collection of standalone examples.

The original SpoutVulkan code was published by **Lynn Jarvis**. The original upstream README is preserved as [`upstream.README.md`](upstream.README.md).

Modifications and library-specific changes in this fork are maintained by **elRottenKotten**.



Despite the somewhat formal setup, this is primarily a personal-use fork and is provided as-is.

I’ll try to review useful pull requests when I have the time, but I don’t currently have plans to turn this into a heavily maintained, general-purpose foundation for a wide range of applications.

If you need something changed, feel free to modify it in your own fork. Don’t hesitate to adapt the code to your needs instead of waiting for changes to land here.
